# Oboe

> Oboe is an AI-powered learning platform — "AI that won't make you stupid" — whose mission is to teach one billion people one trillion things. Anyone can learn virtually any subject through a conversational interface that generates personalized, on-demand courses and lessons. Founded in New York and backed by Homebrew, Oboe is building what it calls the world's first completely generalized AI-powered learning platform. As a consumer web application it does not currently publish a public developer API, SDKs, or developer documentation.
